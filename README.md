# Embu Luxe Stays

Create a modern, elegant, fully responsive website for “LuxeLink EMBU” — a high-end hospitality & accommodation linking service based in Embu, Kenya. The brand connects discerning guests with luxury short-term stays, villas, apartments, boutique lodges and premium properties in and around Embu.

Brand identity:

- Logo concept: Navy-blue house silhouette with a golden key featuring a fleur-de-lis. Primary colours: deep navy (#0A2540 or similar) and gold (#C9A227). Clean white backgrounds, generous whitespace, sophisticated sans-serif typography.

- Tagline: “HIGH-END HOSPITALITY & ACCOMMODATION LINKING SERVICE”

- Tone: Luxury, trustworthy, local expertise, exclusive yet approachable.

Core requirements (must follow strictly):

1. SEO-first architecture

   - Clean, descriptive URLs (e.g. /luxury-villas-embu, /short-stays-embu)

   - Proper heading hierarchy (one H1 per page, logical H2/H3)

   - Meta titles & descriptions optimised for keywords: “luxury accommodation Embu”, “high-end villas Embu Kenya”, “premium short stays Embu”, “boutique lodges near Mount Kenya”, etc.

   - Schema markup for LocalBusiness, RealEstateListing / LodgingBusiness, FAQ

   - Fast loading, mobile-first, Core Web Vitals friendly

   - XML sitemap structure, robots.txt ready, Open Graph & Twitter cards

2. Simple, intuitive navigation

   - Sticky top navigation with: Home | Properties | About | How It Works | Blog / Insights | Contact

   - Clear CTAs on every page (“Enquire Now”, “View Available Properties”, “Speak to Our Team”)

   - Footer with quick links, contact details, social icons, and location (Embu, Kenya)

3. Essential pages & sections

   - Home: Hero with high-quality lifestyle imagery + search/filter bar (location, dates, guests, property type). Featured luxury properties, “Why LuxeLink”, testimonials, destination highlights (Embu, Mount Kenya area), and strong CTA.

   - Properties / Listings: Filterable grid (price, bedrooms, amenities, type). Individual property pages with photo galleries, key amenities, location map, availability calendar placeholder, and enquiry form.

   - About: Brand story, mission (linking guests to exceptional stays), team/local expertise in Embu.

   - How It Works: Simple 3–4 step process for guests and for property owners who want to list.

   - Blog / Insights: SEO content hubs (e.g. “Best luxury stays in Embu”, “Weekend escapes near Embu”, “What makes a high-end short-term rental”).

   - Contact: Form + WhatsApp/phone/email + Google Map of Embu.

4. Design & UX

   - Luxury aesthetic: soft shadows, elegant cards, high-quality image placeholders, subtle gold accents on navy.

   - Extremely simple navigation — no clutter, large tap targets, clear hierarchy.

   - Mobile-first, fully responsive.

   - Accessibility basics (contrast, alt texts, keyboard navigation).

5. Technical & conversion

   - Lead capture forms (enquiry, newsletter, “list your property”).

   - WhatsApp click-to-chat button.

   - Placeholder for future IDX / booking integration or calendar.

   - Performance-optimised images and code.

Output the complete website as clean, production-ready code (preferably Next.js + Tailwind CSS or pure HTML/CSS/JS if simpler). Include all pages, reusable components, and SEO meta tags. Make the structure easy to extend later with a CMS or backend.
